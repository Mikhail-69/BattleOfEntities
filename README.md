# 🎮 Battle of Entities

**Battle of Entities** — это пошаговая RPG-игра, в которой игрок выбирает класс персонажа, сражается с врагами в трёх локациях, прокачивает героя, собирает артефакты и открывает достижения.

## 🚀 Особенности игры

### 🧙 Классы персонажей
| Класс | Характеристики | Способность |
|-------|----------------|-------------|
| **Монстр** | Огромное здоровье, низкая сила | +50 к макс. здоровью после победы |
| **Демон** | Низкое здоровье, высокий урон | Увеличивает множитель урона после каждой победы |
| **Маг** | Средние характеристики | Мощное заклинание раз в 3 хода (урон ×2.5) |

### 🏔 Локации
1. **Тёмный лес** — 2 врага
2. **Горящие горы** — 4 врага
3. **Цитадель тьмы** — 6 врагов (финальный босс)

### ✨ Другие возможности
- 💊 Зелья здоровья (максимум 10 за игру)
- 📦 Артефакты с разными эффектами (+сила, +здоровье, +мана, крит, вампиризм)
- 🏆 Глобальные достижения (разблокируются один раз навсегда)
- 📊 Таблица лидеров (рекорды всех игроков)
- 💾 Сохранение и загрузка прогресса
- 🎵 Фоновая музыка и звуковые эффекты
- 🎨 Динамические цвета локаций

## 🛠 Технологии
- **Язык:** C# (.NET 9.0)
- **UI:** Windows Forms
- **База данных:** SQLite
- **JSON сериализация:** Newtonsoft.Json
- **Аудио:** Windows Media Player COM-компонент

## 🕹 Как играть
1. Введите имя игрока
2. Выберите класс: Монстр / Демон / Маг
3. Нажмите "Новая игра"
4. Сражайтесь с врагами, используя кнопки:
   - **Сражаться** — начало боя
   - **Зелье здоровья** — лечение
   - **Артефакты** — применение бонусов
   - **Сохранить и выйти** — сохранение прогресса
5. Для магов: мощное заклинание автоматически применяется раз в 3 хода при наличии маны
